*mdmaid.txt*  Open Markdown + Mermaid in shared mdmaid.desk

==============================================================================
INTRODUCTION                                            *mdmaid-introduction*

mdmaid.nvim registers saved Markdown sources in mdmaid.desk and opens their
stable document routes. Desk owns rendering, the source watcher, and the
persistent catalog. Whole-document previews update while typing without saving
the source. No source-line/cursor mapping is required.

Requirements: Neovim >= 0.9.0 and a current mdmaid-desk CLI.
Install desk with: >
    npm install --global mdmaid-desk
<
The npm installation requires Node.js >= 22. Telescope is optional.
Run :checkhealth mdmaid to check the CLI. Live buffers and direct TUI opening
require a desk build with preview --document and tui --document --preview.
Older desk versions support saved Web previews with preview.live=false.

==============================================================================
CONFIGURATION                                           *mdmaid-configuration*

>lua
    require("mdmaid").setup({
      mdmaid_path = "mdmaid-desk", -- executable or argv prefix
      desk = {
        auto_start = true,        -- start/reuse shared background daemon
        timeout = 15000,          -- milliseconds per CLI operation
        workspace = nil,         -- optional existing workspace ID
        root = nil,              -- optional root, permits workspace creation
      },
      preview = {
        target = "web",           -- or "tui"
        layout = "split",         -- or "replace"
        live = true,              -- include unsaved changes
        sync_scroll = true,       -- follow source scrolling in split TUI
        debounce = 150,           -- buffer update delay in milliseconds
        auto_start = true,        -- automatically preview saved Markdown
        open_browser = true,
        browser = nil,            -- executable/argv prefix or system default
      },
      keymaps = {
        preview = "<leader>mp",
        stop = "<leader>ms",
        files = "<leader>mf",
        add = "<leader>ma",
        web = "<leader>mw",
        tui = "<leader>mt",
        source = "<leader>me",
      },
    })
<
Set keymaps=false to disable mappings. With desk.auto_start=false, start the
shared service yourself: >
    mdmaid-desk daemon start
<
By default, reuse the deepest registered workspace containing the canonical
source path. Otherwise register the Git worktree root, or source directory
outside Git, with a deterministic workspace ID. Existing artifact-root policies
remain in force. Set desk.workspace to select an existing ID; also set desk.root
to create a missing ID. Set desk.root alone to select/create that exact root.

The .md file must exist before first registration. Once previewing, Neovim
streams unsaved contents to a temporary desk preview tied to that document.
Disk content and shared saved revisions remain intact. Drafts live in memory
and are released on Stop, buffer deletion, exit, or disconnection (2 MiB limit).
With preview.live=false, updates follow disk saves, including atomic saves.

Split TUI views follow the source by proportional document scroll progress.
Wrapped paragraphs are included on Neovim 0.10+. This requires live previews
and a desk service with preview-scroll-v1. Set preview.sync_scroll=false to
disable. Web and replacement views do not synchronize scrolling.

==============================================================================
COMMANDS                                                    *mdmaid-commands*

:MdmaidPreview                                              *:MdmaidPreview*
    Register the current buffer as a live source and open its stable route.
:MdmaidOpen                                                    *:MdmaidOpen*
    Register/open the current buffer even with preview.open_browser=false.
:MdmaidWeb                                                      *:MdmaidWeb*
    Open the whole document in Web. MdmaidOpen is its compatibility alias.
:MdmaidTui                                                      *:MdmaidTui*
    Open the whole document beside the source in a terminal buffer.
:MdmaidTui!                                                    *:MdmaidTui!*
    Use the current window instead. Keep the source buffer, including edits.
:MdmaidSource                                                *:MdmaidSource*
    Return to the source buffer and preserve its cursor/view.
:MdmaidStop                                                    *:MdmaidStop*
    Disconnect this client and cancel pending work. Leave shared desk running.
:MdmaidRestart                                              *:MdmaidRestart*
    Reconnect this client and register the last active document.
:MdmaidFiles                                                  *:MdmaidFiles*
    Pick a tracked document (Telescope or vim.ui.select).
:MdmaidAdd                                                      *:MdmaidAdd*
    Register current file without opening a browser.
:MdmaidRemove                                                *:MdmaidRemove*
    Remove current file from this client's list. Keep it in the desk catalog.
:MdmaidStatus                                                *:MdmaidStatus*
    Show client state, stable document ID, and URL without authentication token.

==============================================================================
KEYMAPS                                                      *mdmaid-keymaps*

Markdown-buffer defaults:
    <leader>mp   Toggle preview/client connection
    <leader>ms   Disconnect client
    <leader>mf   Pick document
    <leader>ma   Register current file
    <leader>mw   Open Web preview
    <leader>mt   Open TUI preview
    <leader>me   Return to source (also available in the TUI buffer)

TUI: q exits and returns to source. MdmaidSource returns to editing while
keeping the TUI available. Save and reopen saved content to submit reviews
or feedback; unsaved previews are reading views.

Telescope: <CR> opens; <C-d> removes a file from this client's list.

==============================================================================
API                                                              *mdmaid-api*

require("mdmaid").setup(opts)                             *mdmaid.setup()*
require("mdmaid").preview.start(file)             *mdmaid.preview.start()*
    Register file or current buffer, then open its document after success.
require("mdmaid").preview.stop()                   *mdmaid.preview.stop()*
    Cancel pending operations and disconnect this client.
require("mdmaid").preview.toggle(file)           *mdmaid.preview.toggle()*
require("mdmaid").preview.status()               *mdmaid.preview.status()*
    Client status including document_id, file, files, and token-free url.

require("mdmaid").desk
    Shared desk CLI client. server and require("mdmaid.server") are compatibility
    aliases. is_running() describes this client's activity, not daemon health.

==============================================================================
MIGRATION                                                *mdmaid-migration*

Install mdmaid-desk and update an explicit mdmaid_path="mdmaid" override.
The private mdmaid serve process, dynamic per-instance ports, old HTTP API,
temporary session files, and process cleanup are removed.

server.auto_start maps to preview.auto_start. Other server options and render
options are retired; configure rendering in mdmaid.desk. Stop, Remove, and
Neovim exit never stop the shared daemon or delete desk documents.

Registration/opening is passive and does not request workflow approval.
